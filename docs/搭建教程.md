# 零基础搭建与打包教程（Windows）

本教程面向完全没有编程经验的人，从零把你手上这份 `photo-cleaner` 源码，变成手机里能用的 App。整个过程约需 **1~2 小时**（大部分时间在下载）。

> 你需要准备：一台 Windows 电脑、一部安卓手机、一根数据线、能联网。

## 一、安装 Flutter SDK

1. 打开浏览器，访问 Flutter 官方下载页：
   **https://docs.flutter.dev/get-started/install/windows**

2. 下载 Windows 版 **Flutter SDK 压缩包**（文件名类似 `flutter_windows_3.x.x-stable.zip`，约 1GB）。

3. 把压缩包**解压**到一个**没有中文、没有空格的路径**，例如：
   ```
   C:\flutter
   ```
   （⚠️ 不要解压到 `C:\Program Files`，会因权限出问题。）

4. 解压后确认 `C:\flutter\bin` 文件夹里有一个 `flutter.bat` 文件，说明解压正确。

---

## 二、安装 Android Studio

1. 访问 **https://developer.android.com/studio** 下载并安装 Android Studio。

2. 安装过程中，**务必勾选**：
   - ✅ Android SDK
   - ✅ Android SDK Platform-Tools
   - ✅ Android SDK Command-line Tools

3. 安装完成后打开一次 Android Studio，按提示完成初始化（选择 Standard 默认即可），直到进入主界面。

---

## 三、验证环境

1. 按 `Win + R`，输入 `powershell`，回车，打开终端窗口。

2. 输入以下命令，把 Flutter 临时加入当前终端的环境变量（每次新开终端都要执行，或用第 3 步永久设置）：
   ```powershell
   $env:Path += ";C:\flutter\bin"
   flutter doctor
   ```

3. （推荐）永久加入 PATH：右键「此电脑」→ 属性 → 高级系统设置 → 环境变量 → 在「用户变量」的 `Path` 里新建一条 `C:\flutter\bin`。

4. `flutter doctor` 会输出一串检查结果。只要 `Flutter` 和 `Android toolchain` 两项是绿色的 `[√]` 就成功了；红色的项按提示修复即可。

## 四、生成工程并放入源码

你手上的 `photo-cleaner` 文件夹里，`lib/` 和 `pubspec.yaml` 是**核心源码**，但还缺少 `android/` 平台目录（它包含无法用文字传递的二进制文件）。我们用 Flutter 自动补齐：

1. 把整个 `photo-cleaner` 文件夹放到一个方便的位置，例如 `D:\photo-cleaner`。

2. 在终端里进入该目录：
   ```powershell
   cd D:\photo-cleaner
   ```

3. 执行（会自动补齐 `android/`、`ios/` 等平台目录，**不会动**我们写好的 `lib/` 源码）：
   ```powershell
   flutter create --org com.example --project-name photo_cleaner .
   ```

4. 完成后，目录里应该多出 `android/`、`ios/`、`.metadata` 等文件。

> 💡 如果执行后提示 `pubspec.yaml` 被修改，别担心，按下一步重新安装依赖即可（源码在 `lib/` 里，不受影响）。

---

## 五、安装依赖

在 `photo-cleaner` 目录下执行：

```powershell
flutter pub get
```

它会自动下载 `photo_manager`、`image`、`provider`、`google_mlkit_image_labeling` 等依赖。

**如果报版本冲突错误**，改用下面命令逐个安装最新兼容版本（会自动写进 `pubspec.yaml`）：

```powershell
flutter pub add photo_manager image provider google_mlkit_image_labeling path_provider
flutter pub get
```

## 六、修改 Android 配置

这一步很简单，按 [`docs/Android配置.md`](Android配置.md) 操作：

1. 打开 `android/app/src/main/AndroidManifest.xml`，加入照片读写权限（文档里有完整片段）。
2. 打开 `android/app/build.gradle`（或 `.kts`），确认 `minSdk >= 21`。

> 用「记事本」或「VS Code」打开这些文件即可。

## 七、连接手机运行

1. **手机开启 USB 调试**：
   - 打开「设置」→「关于手机」→ 连续点击「版本号」7 次，直到提示“已进入开发者模式”。
   - 返回设置 →「开发者选项」→ 打开「USB 调试」。

2. 用数据线连接电脑，手机上弹出「允许 USB 调试」时点**允许**。

3. 终端里确认手机已被识别：
   ```powershell
   flutter devices
   ```
   应能看到你的手机型号。

4. 在 `photo-cleaner` 目录运行：
   ```powershell
   flutter run
   ```
   首次编译较慢（几分钟），完成后 App 会自动安装并打开到手机上。

5. 首次启动会弹出相册权限申请，点「允许」。

---

## 八、打包 APK 安装到手机

不想一直连着电脑时，可以打包成 APK 文件，之后随意安装：

1. 在 `photo-cleaner` 目录执行：
   ```powershell
   flutter build apk --release
   ```

2. 完成后，APK 位于：
   ```
   build\app\outputs\flutter-apk\app-release.apk
   ```

3. 把这个 `app-release.apk` 传到手机（微信/QQ/网盘/数据线都行），点击安装。
   - 若提示「禁止安装未知来源应用」，在弹窗里允许即可。

## 九、常见问题

| 现象 | 解决 |
| --- | --- |
| `flutter` 不是内部或外部命令 | 没把 `C:\flutter\bin` 加进 PATH，回到第三步 |
| `flutter doctor` 提示 Android SDK 缺失 | 打开 Android Studio → Settings → SDK Manager，安装最新 Android SDK |
| 手机连上但 `flutter devices` 看不到 | 换一根数据线；或换一个 USB 口；确认手机上已允许 USB 调试 |
| `flutter pub get` 报版本冲突 | 用第五步的 `flutter pub add ...` 命令 |
| 运行后提示没有权限 | 在手机「设置 → 应用 → 照片整理 → 权限」里手动开启「照片和视频」 |
| 模糊/重复识别不准 | 打开 `lib/services/blur_detector.dart` 或 `duplicate_detector.dart`，调整阈值后重新 `flutter run` |
| AI 分类很久没结果 | 首次会加载本地模型；若设备较旧可耐心等待或关闭 AI 分类使用 |
